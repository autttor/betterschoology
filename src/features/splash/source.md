# Better Schoology Splash Texts

750 potential splash texts for Better Schoology.

## Style rules

- No em dash
- No semicolon
- Short, casual wording
- Prefer real context over generic motivation
- Jokes should sound like something a student would actually say
- Avoid defeatist or self pity humor
- Avoid fake inspirational language
- Avoid corporate, assistant, or chatbot phrasing
- `[name]` is the student's display name placeholder
- State specific lines should only appear when the condition is actually true
